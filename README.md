FUTURE_CS_02 - Phishing Email Detection & Awareness System

Overview

This project was completed as part of the Future Interns Cyber Security Internship. The objective was to analyze verified phishing websites and identify the techniques used by attackers to steal sensitive information from users.

Data Source

PhishTank – Public Database of Verified Phishing Websites

Tools Used

- PhishTank
- Web Browser
- WPS Office
- GitHub

Phishing Samples Analyzed

1. SMBC Bank Phishing Website
2. Allegro Lokalnie Phishing Website
3. Mobile Device Credential Harvesting Website

Phishing Techniques Identified

1. Subdomain Spoofing
2. Domain Lookalike
3. Credential Harvesting
4. Brand Impersonation
5. Use of Suspicious Domains
6. Lack of HTTPS Security

Risk Summary

- High Risk Phishing Websites: 3
- Medium Risk Phishing Websites: 0
- Low Risk Phishing Websites: 0

Key Findings

- All analyzed URLs were verified phishing websites.
- Subdomain Spoofing was the most common attack technique.
- Attackers impersonated trusted brands to deceive users.
- Cloudflare was used in multiple cases to conceal hosting details.
- All phishing websites posed a high risk of credential theft and financial fraud.

Prevention Recommendations

- Verify website URLs carefully before entering credentials.
- Use only HTTPS-enabled websites.
- Avoid clicking links from suspicious emails.
- Enable Multi-Factor Authentication (MFA).
- Verify sender email addresses before responding.
- Never share passwords or OTPs through email links.
